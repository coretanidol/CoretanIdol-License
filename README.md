## ⚖️ Aturan Global / Global Rules

Aturan ini berlaku untuk **SEMUA** lisensi di repo ini, kecuali disebutkan berbeda di folder masing-masing.

### ✅ Yang Diperbolehkan (Global)
- Menggunakan karya untuk referensi pribadi & edukasi dengan credit
- Membuat reaction / commentary / review yang transformatif
- Share link asli dengan menyebutkan sumber

### ❌ Yang Dilarang Keras (Global)
- Re-upload 100% tanpa izin & tanpa transformasi
- Menghapus watermark, credit, atau metadata
- Mengklaim sebagai karya sendiri
- Penggunaan untuk scam, judi, pornografi, ujaran kebencian, atau aktivitas ilegal
- Menjual ulang lisensi gratis sebagai produk berbayar

### 🔖 Format Credit Wajib

Untuk semua jenis penggunaan yang diizinkan:

```
Content by CoretanIdol
Source: https://github.com/coretanidol/CoretanIdol-License
Original: [Link ke konten asli]
Licensed under: [Nama Folder License, contoh: Youtube-License]
```

## ➕ Cara Menambah Lisensi Baru / How to Add New License

Biar repo tetap rapi saat kamu tambah karya baru:

1. Buat folder baru: `Nama-License/` (contoh: `Ebook-License/`)
2. Di dalamnya buat file:
   - `LICENSE.md` - Aturan lengkap
   - `README.md` (opsional) - Ringkasan singkat
   - `COMMERCIAL.md` (opsional) - Jika ada versi berbayar
3. Update tabel **Daftar Lisensi Tersedia** di README utama ini
4. Commit: `feat: add Ebook-License v1.0`

Template `LICENSE.md` universal:

```markdown
# [Nama] License - CoretanIdol

## Deskripsi
Jelaskan karya yang dilindungi...

## Diperbolehkan
...

## Dilarang
...

## Credit
...

## Kontak: coretanidolreport@gmail.com
```
